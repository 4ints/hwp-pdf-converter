# HWP/HWPX to PDF Context Menu Converter 📄➡️📕

Windows 마우스 우클릭 메뉴(Context Menu)에 **"PDF로 변환"** 기능을 추가하여, 한글(.hwp, .hwpx) 문서를 백그라운드에서 한 번의 클릭으로 빠르게 PDF로 변환해 주는 초경량 유틸리티입니다.

---

## ✨ 주요 특징 (Key Features)

*   **⚡ 원클릭 초고속 변환**: 한글 프로그램을 실행해서 따로 'PDF로 저장하기'를 누를 필요 없이, 파일 우클릭 후 클릭 한 번으로 동일 폴더 내에 PDF를 생성합니다.
*   **🤫 완벽한 백그라운드 구동**: 변환 과정에서 한글 프로그램 창이 화면에 뜨지 않으며, 불필요한 터미널 창(검은 화면)의 깜빡임 없이 완전히 백그라운드(`pythonw.exe`)에서 동작합니다.
*   **🛡️ 보안 경고 창 완전 바이패스**: 사용자 PC에 설치된 보안 모듈 DLL(`FilePathCheckerModuleExample.dll`)을 레지스트리에 자동 등록하여, 변환할 때마다 뜨는 한컴 오피스의 자동화 보안 팝업을 깔끔하게 차단합니다.
*   **🔒 안전한 비관리자 권한 등록**: Windows 레지스트리의 `HKEY_CURRENT_USER` 영역을 활용하기 때문에, **별도의 관리자 권한(UAC) 상승 없이** 누구나 안전하게 등록하여 사용할 수 있습니다.
*   **🖥️ Windows 10 & 11 완벽 지원**: 최신 Windows 11의 클래식 메뉴(더 많은 옵션 표시)를 포함하여 완벽하게 통합됩니다.

---

## 📋 사전 준비 사항 (Prerequisites)

이 유틸리티를 정상적으로 사용하려면 컴퓨터에 아래 환경이 구성되어 있어야 합니다.

1.  **한컴오피스 한글** 프로그램이 설치되어 있어야 합니다.
2.  **Python 3.x** 버전이 설치되어 있어야 합니다.
3.  파이썬의 Windows COM 연동을 위해 `pywin32` 패키지가 필요합니다.
    ```bash
    pip install pywin32
    ```

---

## 🚀 설치 및 적용 방법 (Installation)

1.  본 저장소를 클론하거나 코드를 다운로드합니다.
2.  해당 폴더에서 터미널(CMD 또는 PowerShell)을 열고 아래 명령어를 실행합니다.
    ```bash
    python register_menu.py
    ```
3.  실행 즉시 레지스트리 등록 및 보안 모듈 링크 설정이 자동으로 완료됩니다!

---

## 📖 사용 방법 (How to Use)

1.  변환하고 싶은 한글 파일(`.hwp` 또는 `.hwpx`)을 찾습니다.
2.  파일 위에서 **마우스 오른쪽 버튼**을 클릭합니다.
    *   *Windows 11 사용자*: **`더 많은 옵션 표시` (Show more options)**를 클릭합니다.
3.  컨텍스트 메뉴에서 📄 아이콘이 적용된 **`PDF로 변환 (P)`** 항목을 클릭합니다.
4.  약 2~5초 후, 동일한 폴더 안에 원본 파일과 동일한 이름의 `.pdf` 파일이 생성됩니다.

---

## 🗑️ 제거 방법 (Uninstallation)

마우스 우클릭 메뉴와 레지스트리에 등록된 모든 설정을 흔적 없이 완전히 삭제하려면 아래 명령어를 실행하십시오.

```bash
python register_menu.py --uninstall
```
